# Boogeyman 1 Incident Investigation

## Overview

This project documents a SOC-style investigation of the Boogeyman 1 incident. The goal of this report is to analyze suspicious activity, reconstruct the attack timeline, identify indicators of compromise, and recommend detection and response improvements.

## Objectives

- Reconstruct the attack timeline
- Identify suspicious activity
- Analyze PowerShell-related evidence
- Review network-related indicators
- Extract indicators of compromise
- Map attacker behavior to MITRE ATT&CK
- Recommend detection opportunities

## Skills Demonstrated

- Incident investigation
- Log analysis
- PowerShell analysis
- Network analysis
- IOC extraction
- Timeline reconstruction
- MITRE ATT&CK mapping
- SOC reporting

## Project Files

- `report.md` - Full investigation report
- `timeline.md` - Chronological attack timeline
- `iocs.md` - Indicators of compromise
- `screenshots/` - Supporting screenshots
